03 Alternative prioritarie

Meccanismi dichiarati e condizioni osservabili nelle fonti ufficiali.

LearnGitBranching

Visualizzatore, sandbox e tutorial

Comprendere Git attraverso il grafo. Comandi, livelli, undo e git golf per sviluppatori principianti e intermedi.

Da verificare

Repository simulata dichiarata dal sito. Trasferimento al lavoro reale da valutare, senza dedurre che non venga insegnato.

learngitbranching.js.org · github.com/pcottle/learnGitBranching

Oh My Git!

Gioco open source per Git

Strutture visualizzate, carte introduttive e terminale con Git reale. La presentazione include remotes e collaborazione.

Condizioni osservate

Download desktop e manutenzione ridotta dichiarata. Queste condizioni non dimostrano qualità didattica inferiore.

ohmygit.org · github.com/git-learning-game/oh-my-git

GitHub Skills

Imparare GitHub usando GitHub

Per principianti ed esperti. Copia personale del progetto, istruzioni e feedback via Issues e Actions.

Contesto di utilizzo

L’introduzione avviene nella repository del partecipante e dipende dal workflow reale GitHub. Il dominio Skills rinvia a GitHub Learn.

github.com/skills · github.com/skills/introduction-to-github

Microsoft Learn / Azure Repos

Formazione guidata e documentazione

Il modulo Git offre obiettivi, esercizio e valutazione. Azure Repos documenta collaborazione, PR e policy.

Da verificare

Account GitHub, familiarità CLI ed editor tra i prerequisiti introduttivi. L’effetto della composizione tra modulo e documentazione resta da verificare.

learn.microsoft.com/en-us/training/modules/intro-to-git/ · Azure Repos

Pro Git

Libro completo online

Spiegazioni progressive e approfondimenti: installazione, basi, workflow, GitHub, strumenti e internals.

Osservazione circoscritta

La pagina italiana mostra titoli italiani e inglesi e classifica la traduzione tra quelle avviate. Non è un giudizio sull’intero corpus.

git-scm.com/book/en/v2 · git-scm.com/book/it/v2
