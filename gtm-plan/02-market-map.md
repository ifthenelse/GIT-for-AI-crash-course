## Executive summary

Visualizzazione, simulazione e apprendimento per livelli sono già promesse
riconoscibili. LearnGitBranching associa comandi e grafo nel browser; Oh My Git!
usa un gioco con Git reale. GitHub Skills propone esercizi in repository autentiche.
Microsoft Learn e Pro Git coprono concetti e workflow con percorsi e documentazione.

La direzione da verificare è collegare il comportamento di Git alle conseguenze
della collaborazione: seguire uno stesso incidente dal file modificato alla PR,
alle policy e al recupero. Le quattro finestre possono sostenere il percorso;
la loro presenza non dimostra un vantaggio didattico.

Questa ricerca identifica ipotesi, non una posizione libera dimostrata nel mercato.
Il prodotto non è ancora implementato e mancano riscontri di apprendimento.

## Market definition

Imparare a scegliere e spiegare un'azione Git sicura, quindi collaborare su GitHub
o Azure DevOps. Categorie osservate: simulatore visuale, gioco didattico, pratica
su piattaforma reale e riferimento tecnico. Aiuto di un collega, istruzioni cercate
al momento e rinvio dello studio sono alternative plausibili, ancora da verificare.

## Three-layer map

- Diretti: LearnGitBranching e Oh My Git!, pratica Git con rappresentazioni interattive.
- Di categoria: GitHub Skills, Microsoft Learn/Azure Repos e Pro Git, stesso bisogno con pratica reale o spiegazioni strutturate.
- Alternative alla categoria: affiancamento informale, ricerca sul problema, suggerimenti automatici e procedure copiate. Frequenza di queste scelte ignota.

## Priority competitor analysis

### LearnGitBranching

Categoria: visualizzatore, sandbox e tutorial per comprendere Git attraverso il
grafo. Pubblico dichiarato: sviluppatori principianti e intermedi. Meccanismo:
comandi che aggiornano l'albero, livelli, undo e git golf. Il sito dichiara una
simulazione della repository: valutare separatamente il trasferimento al lavoro
reale, senza dedurre che non venga insegnato.
Fonti: [sito](https://learngitbranching.js.org/), [README](https://github.com/pcottle/learnGitBranching).

### Oh My Git!

Categoria: gioco open source per imparare Git. Pubblico: nuovi utenti e partecipanti
curiosi o avanzati. Meccanismo: strutture visualizzate, carte introduttive e terminale
con Git reale; la presentazione include remotes e collaborazione. Il percorso
pubblicizzato richiede un download desktop e i manutentori dichiarano manutenzione
ridotta. Sono condizioni osservabili, non prove di qualità didattica inferiore.
Fonti: [sito](https://ohmygit.org/), [repository](https://github.com/git-learning-game/oh-my-git).

### GitHub Skills

Promessa: imparare GitHub usando GitHub. Pubblico: principianti ed esperti;
l'introduzione nomina nuovi sviluppatori e studenti. Meccanismo: copia personale
del progetto, istruzioni e feedback via Issues e Actions. L'introduzione avviene
in una repository del partecipante: dipende dal workflow reale GitHub. Il precedente
dominio Skills rinvia a GitHub Learn.
Fonti: [organizzazione](https://github.com/skills), [introduzione](https://github.com/skills/introduction-to-github).

### Microsoft Learn e Azure Repos

Categoria: formazione guidata e documentazione del prodotto. Il modulo Git indica
principianti, sviluppatori e studenti, con obiettivi, esercizio e valutazione.
Azure Repos documenta collaborazione, PR e policy. Il modulo introduttivo elenca
account GitHub, familiarità CLI ed editor tra i prerequisiti. Modulo e documentazione
sono risorse distinte: l'effetto di questa composizione sullo studente va verificato.
Fonti: [modulo Git](https://learn.microsoft.com/en-us/training/modules/intro-to-git/),
[Azure Repos](https://learn.microsoft.com/en-us/azure/devops/repos/git/?view=azure-devops).

### Pro Git

Categoria: libro completo online. Pubblico apparente: chi cerca spiegazioni
progressive e approfondimenti. Capitoli da installazione e basi a workflow, GitHub,
strumenti e internals. La pagina italiana classifica la traduzione tra quelle
avviate e mostra titoli italiani e inglesi; non è un giudizio sull'intero corpus.
Fonti: [inglese](https://git-scm.com/book/en/v2), [italiano](https://git-scm.com/book/it/v2).

## Positioning map

Assi qualitativi, non coordinate di mercato misurate:

1. Simulazione controllata rispetto a pratica reale: LearnGitBranching e GitHub
   Skills mostrano i due estremi; Oh My Git! combina visualizzazione e Git reale.
2. Modello mentale rispetto a collaborazione sulla piattaforma: visualizzazione
   del grafo e workflow GitHub/Azure sono enfasi distinte nelle fonti.
3. Esercizio guidato rispetto a consultazione approfondita: giochi/Skills e
   libro/documentazione propongono modi diversi di apprendere.

Il nuovo corso occupa una posizione progettata, non dimostrata: simulazione guidata
che collega Git e collaborazione, con italiano e inglese completi.

**[GAP HYPOTHESIS] Un incidente, dal file alla policy.** Rilevanza da verificare con
i tre pubblici; posizione libera non dimostrata; realizzabilità subordinata a
scenari corretti. Test: spiegare e completare un nuovo workflow senza guida.

**[GAP HYPOTHESIS] Recupero spiegato attraverso conseguenze visibili.** Bisogno
plausibile non validato; reset/merge/recupero già trattati dalle alternative;
realizzabilità da provare sulla fedeltà del simulatore. Test: scegliere e motivare
una strategia che conservi il lavoro condiviso.

## Category dynamics

Comprendere Git visualizzandolo e imparare lavorando su progetti reali sono
narrazioni già presenti. Le fonti non bastano a dichiarare saturazione, crescita
o domanda quantitativa. Evitare la promessa generica «Git interattivo» come prova
di differenziazione.

## Positioning hypotheses

1. **Laboratorio visuale di collaborazione con Git**, direzione consigliata da testare.
2. Palestra di recupero Git: incidenti e conseguenze delle soluzioni.
3. Percorso pratico Git in italiano e inglese: requisito utile, unicità non dimostrata.
