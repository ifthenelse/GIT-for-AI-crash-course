# Beginner audience and introductory copy

This is a desk review of the product brief and the user's expanded audience requirement, not user research. The course also serves people who have never written code. Engineers and architects can use the same introduction before progressing to more technical lessons.

The copywriting skill diagnosis is C: revise the first lesson's introduction while preserving the practical catalog exercise. The copy-editing review checks clarity, consistent terminology and concrete next steps.

A first-time learner needs a reason to track file versions before meeting Git terminology. B01 therefore starts with familiar files and a product catalog, defines a repository and working copy, then explains commits and history, staging, branches, and online collaboration. Each term is defined before it is used in the exercise. Commands and file names use inline code markers for monospace rendering.

The practical task remains unchanged so learners can see the difference between a recorded version and a later draft. The introduction states that programming experience is unnecessary for this exercise, without promising learning outcomes. Beginner comprehension remains a hypothesis to validate with representative learners; no interviews or measured usability results are claimed.
